ジャグラー台管理 PWA（猫アイコン版）

【内容】
- index.html：アプリ本体
- manifest.json：ホーム画面追加用の設定
- sw.js：オフライン表示・更新用
- icon-192.png / icon-512.png：今回の猫アイコン（白背景）

【公開方法】
このフォルダ内のファイルをすべて、GitHub Pages / Netlify / Vercel などのHTTPS対応ホスティングにアップロードしてください。
公開されたURLを友人に共有できます。

【iPhoneでの追加】
1. Safariで公開URLを開く
2. 共有ボタンを押す
3.「ホーム画面に追加」を選ぶ

【データについて】
記録は各端末のブラウザ内に保存されます。URLを共有しても、他の人と記録が自動共有されることはありません。
端末間で移す場合はアプリ内の「書き出し」「読み込み」を使ってください。

※既存のアプリコード・レイアウト・保存キーは維持し、アイコン画像のみ今回の猫画像に差し替えています。
